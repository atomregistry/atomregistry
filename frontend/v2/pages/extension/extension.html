INSTALLATION

Up and Running in 60 Seconds

Manual install beta

This extension is installed from a ZIP file, not from the Chrome Web Store yet. Enable Developer Mode, unzip the download, and load the extracted folder as an unpacked extension.

1

Download the Extension

Chromium extensions from zip - no Chrome Web Store required.

Download atom-registry-extension.zip
2

Unzip the File

Extract to a permanent folder. Don't delete it - Chrome needs it to stay loaded. Right-click → Extract All on Windows, double-click on Mac.

Important - Check for nested folders

After extracting, open the folder. If you see another folder inside rather than files like manifest.json, go into that inner folder - that's the one you select in step 4. Chrome requires manifest.json to be at the root of the folder you load, not buried inside a subfolder.

3

Open Extensions Page

Navigate to chrome://extensions and toggle Developer Mode on in the top-right corner.

4

Load Unpacked

Click Load unpacked and select the extracted folder. The Atom Registry extension appears in your toolbar immediately.

5

Pin & Browse

Click the puzzle piece icon in Chrome's toolbar, find Atom Registry, and pin it. Then type cosmos.atom in your address bar and enter the decentralized web.

Resolver Only.

Atom Registry Browser is designed as a resolver and registry companion. It does not hold private keys, does not sign transactions automatically, and does not collect browser history. Resolution checks on-chain Atom Registry records and sends you to the registered destination.
