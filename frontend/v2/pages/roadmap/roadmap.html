IBC Expansion

From Cosmos Hub registry to interchain-native identity & payment layer, then handed over to Cosmos Hub governance - validators and ATOM holders decide every future move. Seven primitives no other naming protocol on Cosmos has combined.

Sign-In with Atom Registry (SIWA)

OIDC-style authentication via your domain. dApps integrate one library, users log in with alice.atom - Registry signs a verifiable challenge proving ownership without exposing the underlying wallet. EIP-4361 (SIWE) equivalent for the Cosmos ecosystem. The fastest v3 deliverable - mostly a JS library and a published spec; no contract changes required for the base flow.

JS library + spec doc Signature verify No contract change
02

Atomic domain swaps (HTLC)

Trade names trustlessly with optional ATOM top-up. mydomain.atom ↔ otherdomain.atom + 50 ATOM settles in a single atomic step via hash time-lock. No escrow service, no counterparty risk. Standard primitive, well-understood.

HTLC swap · ~2 weeks · zero-fee P2P
03

Atom Registry Streams

Recurring payments without recurring signing. Stream 100 ATOM/month to alice.atom with per-block balance flow. Sender escrows once, recipient withdraws anytime, cancel is atomic. Single CosmWasm contract following the Sablier pattern.

Sablier-style · ~2-3 weeks · per-second accrual
04

IBC-native multi-chain payments

One name, every Cosmos rail. Recipient declares accepted denoms per chain (ATOM on cosmoshub-4, USDC on Noble, OSMO on Osmosis, REGEN on regen-1). Sender wallet picks the optimal IBC route via Packet Forward Middleware. Mostly a frontend + metadata extension on top of mature primitives.

payment.<chain-id>.address · ~3-4 weeks · PFM hooks
05

Security-hardened contract refresh

Coordinated upgrade of all nine deployed CosmWasm contracts: tightened authorization paths, reduced gas surface, hardened admin transfer flows, plus quality-of-life additions (owner self-mint, batch operations, richer query endpoints). Time and audit budget bound, not technical risk.

Audit pass · ~5-8 weeks · CosmWasm migrate · zero state loss
06

Cross-chain trust score (ICA)

dSSL attestations aggregate into a portable Trust Score. Through Interchain Accounts, the score is queryable from Osmosis, Stargaze, Juno - any IBC chain with ICA host enabled. A name's reputation travels with it. Depends on partner chain ICA support; rollout is chain-by-chain.

ICA host · ~1-2 months · dSSL aggregator
07

Handover to Cosmos Hub governance

Atom Registry becomes an official native protocol of Cosmos Hub. From this point on, Cosmos Hub governance decides what happens next - every protocol upgrade, every contract migration, every direction call goes through on-chain proposals voted by ATOM holders. Admin keys retire to a community DAO controlled by the validator set. Hardest because political + governance proposal needs validator buy-in and time.

Cosmos Hub native · governance proposal · validator votes · longest lead time

Ecosystem expansion

Once governance lives at Cosmos Hub (v3), the community decides what to build next. The v5 backlog: native SDKs, embeddable widgets, mobile coverage, public indexer APIs, and the long research track for cross-chain NFT portability.

SDKJS · mobile
APIindexers
NFTresearch
01
Public JS SDKatom-registry-sdk npm package: resolve, pay, profile, DID - in a few lines. The single most-requested integration surface.
02
Embeddable widget libraryDrop-in Pay buttons, profile cards, name lookups for third-party sites. Just include a script tag.
03
Mobile SDKs (iOS + Android)Native wrappers around the JS resolver core. Resolve names and prepare TXs inside any mobile dApp.
04
Public marketplace + registry APIIndexer-friendly REST + GraphQL endpoints for dashboards, bots and analytics. Compatible with the ENS subgraph pattern.
05
Domains as portable ICS-721 NFTsTrade names cross-chain through any Cosmos NFT marketplace (Stargaze, Mintscan etc.) without breaking name resolution. Big engineering challenge - state sync between Registry storage and the NFT wrapper, IBC ownership tracking, edge cases for subdomain TLDs. Long-term research track.
Heading note

Roadmap is directional, not contractual.

Priorities may shift based on community feedback, security findings, audit scheduling and Cosmos Hub network changes - but the direction stays the same: ownership on-chain, no renewals, no custody, no renting names from anyone.
