HOW IT WORKS

1. Build — Create a self-contained HTML file. No external CDN links, no Google Fonts, no external images. Everything inline. Under 100KB.

2. Verify — Connect Keplr. Enter your domain name. We verify you own it against the Atom Registry contract on-chain.

3. Deploy — Upload your HTML. Pay 5 ATOM one-time storage fee. Sign with Keplr. Your page is written to CosmWasm state on Cosmos Hub permanently.

4. Edit — Update anytime. No fee — just gas. Every version is preserved on-chain with a timestamp.

5. Browse — Install the Atom Registry Browser Extension. Type your domain in Chrome. The extension fetches your HTML from the chain and renders it directly. No server. No DNS. Just the chain.

REQUIREMENTS
Keplr wallet with Cosmos Hub configured
A registered domain on Atom Registry that you own
5 ATOM in your wallet for first-time storage (+ gas)
Self-contained HTML file under 100KB (no external dependencies)
Atom Registry Browser Extension to view on-chain sites
